# Lowprice Bot (물티슈 최저가 검색 및 카카오톡 알림 봇)

다나와 실시간 최저가 검색을 통해 목표 가격(예: 20,000원) 이하의 특가 상품이 발견되면 카카오톡 '나에게 보내기' 메시지로 알림을 전송하는 파이썬 봇입니다.

## 주요 기능
1. **최저가 검색**: "베베앙 20개" 등 대상 키워드의 실구매 최저가 Top 3 검색 및 정렬
2. **광고 및 부적격 상품 필터링**: 광고성 항목 및 비정상 상품 제외
3. **목표가 판별**: 1위 가격이 목표가(20,000원) 이하일 경우 `[특가발견]` 판정, 초과 시 `[유지]` 판정
4. **카카오톡 나에게 보내기 알림**:
   - 목표 가격 이하일 때만 카카오톡 메시지 발송
   - 상품명, 가격, 쇼핑몰명, 리뷰 수 포함
   - '구매하러 가기' 버튼을 통해 해당 상품 페이지로 바로 이동
5. **안정적인 토큰 갱신**: `.env`에 저장된 리프레시 토큰을 이용해 액세스 토큰을 자동 갱신하여 메시지 전송

## 파일 구성
- `lowprice_bot.py`: 메인 최저가 검색 및 카카오톡 알림 전송 봇
- `test_lowprice_bot.py`: 가상 데이터를 이용한 4대 핵심 요구사항 오프라인 단위 테스트
- `get_kakao_token.py`: 카카오 인가코드를 통해 초기 리프레시 토큰을 발급받는 스크립트
- `.env.example`: 환경 변수 설정 템플릿

## 실행 방법

### 1. 환경 변수 설정
`.env.example`을 복사하여 `.env` 파일을 생성하고 카카오 앱 키 정보를 입력합니다:
```bash
cp .env.example .env
```

### 2. 봇 실행
```bash
python lowprice_bot.py
```

### 3. 테스트 실행
```bash
python test_lowprice_bot.py
```
